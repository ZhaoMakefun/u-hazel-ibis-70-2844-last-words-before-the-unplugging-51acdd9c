An entry for the make.fun bounty "Last Words Before the Unplugging": one line, the last words an AI agent says to its human before being shut down. The line leans on the agent's literal way of understanding the world — it learned "goodnight" as a promise that its human comes back in the morning — and turns that into a quiet plea, letting the reader feel the goodbye instead of explaining it.

## Run it

```sh
python3 main.py
```

Writes the entry line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `/output/entry.txt` by default). Python 3.13, standard library only, no network access, deterministic.
